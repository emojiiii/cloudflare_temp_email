# 登录入口与凭据

通过独立的 `/login` 页面登录用户账号或管理后台。

| 入口 | 用途 | 登录凭据 |
|------|------|----------|
| `/login`（或 `/:lang/login`） | 登录或注册账号 | 用户邮箱与密码，或用户名 `admin` 与管理员密码 |
| `/`（或 `/:lang/`） | 打开单个邮箱，查看收件箱、发件箱和邮箱设置 | 邮箱会话 Token（Address JWT）；启用 `ENABLE_ADDRESS_PASSWORD` 后也可使用邮箱密码；再同时启用 `ADDRESS_PASSWORD_LOGIN_ONLY` 后，登录页仅提供邮箱密码登录 |
| `/user`（或 `/:lang/user`） | 登录用户中心，管理一个用户账号下绑定的多个邮箱 | 未启用 `DISABLE_USER_SYSTEM` 时可用；使用用户账号邮箱与密码、Passkey 或已配置的 OAuth2 |
| `/admin`（或 `/:lang/admin`） | 进入管理后台 | 用户名 `admin` 和 `ADMIN_PASSWORDS` 中的管理员密码。启用用户系统时，也可使用具有 `ADMIN_USER_ROLE` 的用户账号 |

未登录时打开用户中心或管理后台会进入 `/login`。从管理后台进入时会预填用户名 `admin`。

使用管理员密码登录后，可以用同一会话打开收件箱和用户中心。收件箱可以按邮箱地址筛选，用户中心里的邮箱地址可直接打开对应收件箱。

站点访问密码由 `PASSWORDS` 单独控制。让访客直接访问登录和注册页时，移除 `PASSWORDS`，保留管理员密码。使用「管理后台 → 用户 → 用户设置 → 允许用户注册」开启注册。设置 `DISABLE_ANONYMOUS_USER_CREATE_EMAIL=true` 后，创建邮箱需要先登录用户账号。

用户账号的登录邮箱不会自动成为收发邮件的邮箱地址。登录用户中心后，可在“收件箱”页签查看邮件；如需直接打开单个邮箱，可从邮箱列表选择“进入邮箱”。只登录某个邮箱也不会自动登录用户中心。
